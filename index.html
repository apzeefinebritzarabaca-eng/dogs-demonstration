01 • Introduction

What is the Math object?

The JavaScript Math object is used to perform mathematical operations on numbers.

Math properties

Provide useful mathematical constants, such as π and Euler’s number.

Math methods

Perform calculations, such as rounding numbers, finding square roots, and choosing the highest or lowest value.

Remember: properties are values (for example, Math.PI); methods are actions you call with parentheses (for example, Math.sqrt(25)).

03 • Math methods

Methods you can use

Math.round(x)

Rounds x to the nearest integer.

Math.ceil(x)

Rounds x up to the nearest integer.

Math.floor(x)

Rounds x down to the nearest integer.

Math.abs(x)

Returns the absolute value of x.

Math.sqrt(x)

Returns the square root of x.

Math.pow(x, y)

Returns x raised to the power y.

Math.max(a, b, …)

Returns the highest value.

Math.min(a, b, …)

Returns the lowest value.

Math.random()

Returns a random number from 0 (inclusive) to 1 (exclusive).

Math.sin(x), cos(x), tan(x)

Trigonometric functions; angles are in radians.

Math.log(x)

Returns the natural logarithm of x.

Math.exp(x)

Returns E raised to the power x.
